お手本が鳴らないときは「もう一度聞く」を押してください（イヤホンをつないだあとなど）。
    英文リストと設定

    英文のリストは「セット」ごとに名前を付けて、いくつでも保存できます。下で編集しているのは、最初の画面で選んでいるセットです。英文と和訳はそれぞれの欄に1行に1文ずつ入れ、同じ行どうしが組になります（和訳は空でも可）。「隠す語句」に英文の一部を入れると、カードではその部分が隠れ、言えたところから表示されます（判定のあとは全部表示）。1行に複数あるときは「,」で区切ります。辞書の形のままで大丈夫です（「get back to (sb)」の括弧の部分は隠さず、「look forward to」は looked なども、「make up one's mind」は my mind なども隠します）。

    書き出したファイルは、このブラウザのデータが消えたときの控えになります。読み込むと、同じセットは保存が新しい方が残り、ないセットは追加されます。

    iPhone ではマイクを使い始めると、お手本の声が小さくなることがあります。そのときは音量を上げてください（自然な声・Google の声に効きます。端末の声には効きません）。

    Google の自然な声（任意）

    1. Google Cloud コンソールでプロジェクトを作り、支払い情報を登録する（毎月の無料枠があり、このアプリの使い方ならまず超えません）
    2. Cloud Text-to-Speech API を「有効にする」
    3. 認証情報で「認証情報を作成」→「API キー」
    4. 作ったキーを開き、「アプリケーションの制限」を「ウェブサイト」にして https://elutely.github.io/* を追加、「API の制限」で「Cloud Text-to-Speech API」だけを選んで保存
    5. AIza で始まるキーをコピーして、下に貼り付ける

    使っていません。キーはこの端末の中だけに保存され、同期もされません。

    スマホと PC の同期（GitHub）

    1. GitHub の合言葉（トークン）作成ページを開く（「gist」だけにチェックが入っています）
    2. Expiration（有効期限）を選んで、いちばん下の「Generate token」を押す
    3. 表示された ghp_ で始まる文字列をコピーして、下に貼り付ける

    同期していません。記録と英文リストはこのブラウザの中だけに保存されています。

    診断ログ

    お手本が鳴らないなどの不具合を調べるための記録です（この端末の中だけ、同期しません）。

    
      
    
      
    PC の Chrome 向けに作っています。Safari（iPhone）も音声認識に対応していますが、途中で聞き取りが止まることがあります。Firefox は非対応。音声認識はブラウザの機能を使うため、オンラインで使ってください。ファイルを直接開くと、文ごとにマイクの許可を聞かれます。URL（https か localhost）で開くと許可が記憶されます。
